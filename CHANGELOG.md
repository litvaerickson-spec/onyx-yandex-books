## [v1.3.6] - 2026-10-05

### Bug Fixes & Improvements
- **Устранение критической ошибки при нажатии на «Содержание»**:
  - Версия базы данных SQLite (`DATABASE_VERSION`) повышена до `4`.
  - В методе `onUpgrade` и методах работы с закладками (`getBookmarks`, `addBookmark`, `deleteBookmark`) внедрено автосоздание таблицы `bookmarks` (`CREATE TABLE IF NOT EXISTS`) и тотальная защита `try-catch`, что полностью исключает сбой `SQLiteException: no such table: bookmarks` при обновлении приложения без переустановки.
  - Окно «Содержание» (`showTableOfContentsDialog`) полностью защищено от падений.
- **Устранение бага ложного 100% прогресса и закидывания в конец книги**:
  - Исправлен алгоритм `extractProgress` в `YandexBooksApiClient`: поле `progress` на корневой карточке библиотеки Bookmate (целочисленный статус) больше не интерпретируется как доля $1.0 = 100\%$.
  - Значение `1.0` теперь распознается как $1\%$ (первый процент книги), если статус не равен явно `finished`/`read`.
  - Поиск прогресса в первую очередь опрашивает специализированные вложенные объекты позиции (`last_reading_position`, `reading_position`, `position`).
  - Ликвидировано ошибочное переопределение полки в «Прочитано» и закидывание в главу 9 (последнюю страницу тиража/выходных данных) при открытии книги.
- **Исправление двусторонней облачной синхронизации позиции чтения**:
  - В `DatabaseHelper` устранено затирание прогресса: серверные данные со смартфона теперь имеют приоритет при более свежем `timestamp` или при обнаружении локально искаженного значения 100%.
  - При миграции базы данных на версию 4 автоматически очищаются ложные 100%-метки на не завершенных книгах.
  - В `ReaderActivity.resolveInitialPositionAndOpen` при наличии известного индекса главы (`targetChapter`) читалка открывает именно целевую главу и страницу, не пересчитывая ее приближенно через общий байтовый объем книги.
  - В `applyCloudProgressIfNewer` облачный индекс главы применяется напрямую.
  - При повторном открытии книги, прочитанной до конца, чтение начинается с Главы 1, а не со страницы выходных данных.
- **Коррекция типографики автора**:
  - В диалоге «О книге» ФИО автора переведено на обычный/тонкий шрифт (`Typeface.NORMAL`), обеспечивая визуальное разделение от жирного названия книги.

## [v1.3.5] - 2026-10-05

### Bug Fixes & Improvements
- **Точная синхронизация позиции чтения без ложных перескоков и затирания**:
  - Реализован взвешенный расчет общего прогресса по фактической длине глав в байтах/символах (`calculateChapterLengths`, `totalBookLength`) вместо наивного равномерного деления на количество элементов в оглавлении EPUB.
  - Ликвидирована ошибка, когда прогресс 51% из облака перескакивал на главу «Слова благодарности» в конце книги (составляющую лишь 1.5% объема) и сбрасывал прогресс до 40%.
  - Добавлен флаг `isInitialLoading`, блокирующий вызов `saveProgress()` при первичном открытии книги и отображении первой страницы до первого действия пользователя (листание или перемещение слайдера).
  - Позиция точно привязывается к странице через внутриглавное символьное смещение `anchorCharOffset`.
- **Типографика списков книг**:
  - ФИО автора книги теперь отображается нормальным/тонким шрифтом (`android:textStyle="normal"`), четко и гармонично отделяясь от жирного названия книги.
- **Трехсекционная панель форматирования в стиле Onyx NeoReader**:
  - Панель форматирования разделена на 3 подвкладки с просторной компоновкой, исключающей обрезку текста на экранах E-Ink:
    - `[ Вид ]`: ползунок размера шрифта (`—` [SeekBar] `+`, от 12 до 36 sp), выбор гарнитуры (`Serif ∨`, `Sans-Serif ∨`, `Monospace ∨`), настройка абзацного отступа (`0 px ∨`, `20 px ∨`, `32 px ∨`, `44 px ∨`).
    - `[ Формат ]`: переключатель жирности текста (`Жирный` / `Обычный`), слоговые переносы TeX (`Включены` / `Отключены`), режим контрастности E-Ink (`Высокий` / `Обычный`).
    - `[ Между строк ]`: межстрочный интервал (`1.00x ∨`, `1.25x ∨`, `1.50x ∨`, `1.75x ∨`), боковые поля (`Узкие (18) ∨`, `Средние (32) ∨`, `Широкие (48) ∨`), вертикальные поля (`Малые ∨`, `Стандарт ∨`, `Большие ∨`).
- **Полноценное оглавление и менеджер закладок**:
  - В окне «Содержание» реализованы 2 сегментированные вкладки: `[ Оглавление ]` и `[ Закладки ]`.
  - В `[ Оглавление ]`: перечень глав с подсветкой текущей читаемой главы (`▶ Глава X (читается)`).
  - В `[ Закладки ]`: кнопка `[ + Добавить текущую страницу в закладки ]`, список сохраненных мест с номером главы, страницы, цитатой (сниппетом текста), датой и временем создания, переходом по клику и кнопкой удаления `✕`.
  - В SQLite создана таблица `bookmarks` с сохранением закладок между сессиями.

- **Двукратное уменьшение межстрочного интервала заголовков**:
  - В разметке `item_book.xml` уменьшены межстрочные интервалы (`lineSpacingMultiplier="0.9"`) и отключен лишний системный паддинг шрифта (`includeFontPadding="false"`).
  - Списки книг стали значительно компактнее, без избыточных пустот по вертикали.
- **Интерфейс онлайн-читалки в стиле Onyx NeoReader**:
  - Верхняя панель: кнопка «Назад» (`<`), заголовок книги, кнопка E-Ink обновления экрана `[ Сброс ]`, кнопка закрытия меню (`✕`).
  - Нижняя панель: название главы с кнопками смены глав (`<<`, `>>`), интерактивный слайдер страниц `SeekBar` с кнопками шага и индикатором `X/Y (Z%)`.
  - Вкладка `[ Содержание ]`: интерактивное оглавление с индикацией текущей читаемой главы.
  - Вкладка `[ Прогресс ]`: процент прочтения, глава, страница и кнопка синхронизации с облаком Яндекс.
  - Вкладка `[ Формат ]`: панель настройки кегля шрифта (`A-`/`A+`), полей, межстрочного интервала, переносов и жирности.
  - Обработка кнопки «Назад»: закрытие открытых панелей меню перед выходом из читалки.

## [v1.3.1] - 2026-10-04

### Features
- **Фоновая асинхронная пагинация (Async Pagination)**:
  - Пагинация вынесена в фоновый `ExecutorService` с версионированием задач (`paginationTaskId`). UI-поток полностью разгружен, что исключает зависания и ошибку Android ANR («Приложение не отвечает»).
  - Оптимизирован алгоритм расчета ширины строк в `TextPaginator` до $O(N)$ (линейное суммирование ширины слов без повторного переизмерения строки).
  - Внедрен потокобезопасный LRU-кэш слоговых переносов в `TeXHyphenator` для частотных русских слов.
  - Сохранение точной позиции чтения (`startCharOffset`) при изменении размера шрифта или полей страницы.
- **Устранение остаточных артефактов E-Ink (Ghosting Fix)**:
  - Замена анимированных спиннеров загрузки `ProgressDialog` на статические E-Ink диалоги без 60fps круговой анимации.
  - Автоматический аппаратный сброс дисплея `EpdController.requestFullRefresh` при закрытии диалогов, в `onResume` и при открытии первой страницы книги.
- **Селектор цвета текста кнопок меню ридера (`btn_eink_text_color`)**:
  - При нажатии кнопок меню текст становится контрастно белым на черном фоне, исключая эффект залипания «черным-по-черному».
- **Защита от наложения текста на нижний колонтитул (Footer Margin Protection)**:
  - Резервирование высоты `footerReservedHeightPx = 44px` в `TypographyConfig` и жесткий барьер отрисовки `maxAllowedTextBottom` в `ReaderCanvasView`.
  - Гарантированный зазор между текстом книги и колонтитулом (номер страницы, глава, процент) составляет > 75 пикселей.

## [v1.2.6] - 2026-10-04

### Features
- Deep black monochrome rendering via Software Skia (`hardwareAccelerated="false"`) matching Regal E-Ink mode
- Contrast toggle in reader settings menu: `[ Контраст: Высокий / Обычный ]`
- Automatic bidirectional reading progress synchronization with Yandex Cloud API
- Detailed reader footer displaying current chapter title (`Гл. X/Y • Название`) and global reading percentage (`Стр. P/N (Z%)`)
- Two-line book annotations and offline memory tags (`✔ В памяти` / `☁ В сети`) in shelf cards
- Modal dialog «О книге» with full scrollable annotation, metadata, and actions

### Bug Fixes
- Fixed text clipping on the right edge by matching pagination measurement font metrics with Canvas drawing Paint (Serif Bold)
- Increased physical margins to comfortable 42px on left/right and 36px/44px top/bottom
- Optimized auth screen layout and resized QR code to 170dp, preventing vertical scroll on 758x1024 screens
- Fixed chapter position recovery on initial opening of in-progress books

## [v1.2.5] - 2026-10-02

### Features
- Native EPUB streaming and offline downloading from Bookmate/Yandex Books API (`/content/v4`)
- Lightweight `EpubParser` using `java.util.zip.ZipFile` with OPF spine ordering
- Automatic export to `/sdcard/Books/YandexBooks/` for integration with Onyx system library
- High-contrast E-Ink Carta UI styling with dark active tab markers and 2px borders
- Async cover loader `CoverLoader` with disk and memory caching

### Bug Fixes
- Fixed multi-page user library loading (`per_page=100`)
- Fixed author name parsing from JSON object arrays

## [v1.2.4] - 2026-10-02

### Features
- Multi-channel auth: in-reader browser (Granny/Domik mode), QR code, cloud bridge (ntfy.sh), local Wi-Fi, manual token input
- Custom `Tls12SocketFactory` and X509TrustManager for Android 4.4 KitKat TLS 1.2/1.3 compatibility

## [v1.2.0] - 2026-10-01

### Features
- Initial release of Yandex Books Lite for Onyx Boox Darwin (3, 5, 6)
- Native Canvas rendering engine with low memory footprint (~15-20 MB RAM)
- TeX Hyphenation (Franklin-Liang algorithm) for Russian and English
- Justified text layout without word spacing artifacts
- Hardware page turn key interception for Onyx Boox Darwin
- EPD anti-ghosting waveform refresh control
