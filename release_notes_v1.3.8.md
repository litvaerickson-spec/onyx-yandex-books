# Яндекс Книги v1.3.8

## 🚀 Что нового в версии 1.3.8:

### 1. Новый ярлык приложения и официальное название
- **Ярлык (Иконка)**: Создан новый логотип по требованиям эргономики E-Ink и брендбука: большая контрастная красная буква «Я» на верхние 2/3 площади со скругленными углами, а внизу на всю ширину логотипа расположена черная плашка с четкой белой надписью «КНИГИ» (высотой ~1/3, не перекрывающая букву «Я»).
- Пиксель-перфектные иконки сгенерированы во всех плотностях (`mdpi`, `hdpi`, `xhdpi`, `xxhdpi`).
- **Название**: Официальное имя приложения обновлено на **«Яндекс Книги»** (без приписки «Lite»).

### 2. Подлинное оглавление TOC (NCX / NAV) и склейка фрагментов глав
- **Причина проблем ранее**: Многие издатели разбивают текст одной главы на произвольные мелкие XHTML-файлы по 50–100 КБ. Старый парсер воспринимал каждый файл как отдельную главу («Глава 14», «Глава 15»), из-за чего оглавление теряло названия, а текст главы посреди предложения обрывался на границе файла, оставляя нижнюю половину экрана пустой при уменьшении шрифта.
- **Решение**:
  - В `EpubParser` внедрен полный парсер стандарта оглавления EPUB 2 NCX (`toc.ncx`) и EPUB 3 NAV (`nav.xhtml`).
  - Все куски и файлы из `<spine>` теперь автоматически склеиваются в единый непрерывный текст главы по реальным смысловым границам книги.
  - В окне «Содержание» отображаются настоящие авторские названия глав.
  - Экран ридера полностью заполняется текстом при любом выбранном размере шрифта.

### 3. Очистка артефактов `[OBJ]` и нежелательных спецсимволов
- Полностью удалены артефакты `[OBJ]` (`\uFFFC` - Object Replacement Character), возникавшие на месте скрытых тегов изображений и HTML-объектов.
- Очищены символы `\uFFFD`, `\uFEFF`, zero-width spaces (`\u200B`, `\u200C`, `\u200D`) и мягкие переносы `\u00AD`.

### 4. Нормализация межабзацных интервалов и красная строка
- Устранены гигантские двойные отступы между абзацами. Обычные абзацы начинаются со следующей строки с аккуратным абзацным отступом (красной строкой).
- Пустая строка разрешена строго для смысловых авторских разделителей (`<hr/>`, `* * *`) с уменьшенным интервалом (`lineHeight * 0.6f`).

### 5. Бесшовная синхронизация прогресса с мобильным приложением
- База данных SQLite обновлена до версии `5`.
- При обновлении старые фрагментированные списки глав очищаются и локально перепарсиваются из кэшированного EPUB за доли секунды без расхода трафика.
- Процент чтения со смартфона точно отображается на реальные главы и страницы без ложных перескоков.
