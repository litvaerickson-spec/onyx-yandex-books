# Release Notes — Яндекс Книги Lite v1.5.19-beta

> [!NOTE]
> **Статус выпуска**: Предварительная бета-версия (Beta / Preview).
> Данная сборка решает ключевую проблему доставки обновлений по воздуху (OTA Self-Update) на электронные книги Onyx Boox: внедрен мульти-стратегический поиск релизов на GitHub, устранена блокировка обновлений из-за предрелизных и бета-сборок, реализована автоматическая проверка при включении Wi-Fi, а также добавлена полная поддержка современных версий Android (Android 8/9/10/11) без падений установщика пакетов.

**Дата релиза**: 1 ноября 2026 г.  
**Целевые платформы**: Onyx Boox Darwin 7, Darwin 6 (Carta Plus 300 DPI), Darwin 1 (Android 4.2.2 Jelly Bean, API 17, Rockchip RK3026), Darwin 3, 5 (Android 4.4.4 KitKat, API 19, Freescale i.MX6), Onyx Boox Livingstone, Poke, Nova, Note, Tab, Leaf, Page, Palma и все электронные книги на базе Android с экранами E-Ink Carta.

## 🚀 Основные исправления и улучшения в версии 1.5.19-beta

### 1. Бесперебойная доставка обновлений по воздуху (OTA) на ридеры
* **Мульти-стратегический поиск обновлений (`AppUpdateManager.fetchLatestRelease`)**:
  * **Стратегия 1 (Releases List API)**: Запрос к `releases?per_page=10` с парсингом всех доступных версий. Это устранило коренную причину бага, когда GitHub API эндпоинт `/releases/latest` полностью игнорировал предрелизы и бета-версии. Теперь ридер всегда находит самую свежую версию с APK-дистрибутивом.
  * **Стратегия 2 (CDN Fallback `version.json`)**: Прямое обращение к статическому манифесту на `raw.githubusercontent.com`. Этот канал не имеет ограничений по лимитам запросов GitHub API (60 req/hr) и безотказно работает на любых сетях.
  * **Стратегия 3 (Latest Fallback)**: Резервное обращение к эндпоинту `/releases/latest`.
* **Универсальный парсер релизов (`parseReleaseFromJson`)**: Единый отказоустойчивый разбор объектов релизов как из массивов GitHub Releases API, так и из статического `version.json`.

### 2. Автоматическое обнаружение обновлений при подключении Wi-Fi
* **Динамический сетевой приемник (`ConnectivityManager.CONNECTIVITY_ACTION`)**:
  * На электронных книгах с E-Ink экранами модуль Wi-Fi автоматически отключается в спящем режиме ради экономии батареи. Ранее проверка выполнялась только один раз при старте приложения до того, как Wi-Fi успевал соединиться.
  * Теперь при поднятии Wi-Fi соединения `networkReceiver` в `MainActivity` мгновенно активирует тихую проверку обновлений в фоне и выгружает очередь офлайн-синхронизации.
  * Добавлена фоновая проверка в `MainActivity.onResume()` при активном сетевом подключении.
* **Наглядная индикация на главном экране**:
  * При обнаружении обновления на верхней панели сразу загорается высококонтрастная кнопка с номером новой версии (например, `v1.5.19-beta`).
  * Для пользователя автоматически выводится контрастный E-Ink диалог с описанием изменений и кнопкой **«Обновить»**.

### 3. Совместимость с современными версиями Android (Android 8/9/10/11)
* **Разрешение `REQUEST_INSTALL_PACKAGES`**: В `AndroidManifest.xml` добавлено системное разрешение `android.permission.REQUEST_INSTALL_PACKAGES`, необходимое на Android 8.0+ (включая Onyx Boox Darwin 7 на Android 9 Pie) для запуска системного PackageInstaller.
* **Обход `FileUriExposedException`**: В `AppUpdateManager.installApk` добавлен безопасный программный обход строгой политики StrictMode для Android 7.0+ (API 24+) через вызов `disableDeathOnFileUriExposure` и флаг `FLAG_GRANT_READ_URI_PERMISSION`.
* **Отказоустойчивый выбор директории для загрузки APK**: Трехуровневый fallback (`Environment.DIRECTORY_DOWNLOADS` $\to$ `context.getExternalFilesDir` $\to$ `/sdcard/Download`) гарантирует успешное сохранение файла обновления даже при нестандартных правах доступа к хранилищу.

### 4. Комплексная верификация и тестирование
* **45 автоматических тестов ядра (`verify_core_logic.py`)**: Добавлен `[ТЕСТ 45]`, подтверждающий корректность мульти-стратегического поиска, манифеста `version.json`, сетевого ресивера `CONNECTIVITY_ACTION`, разрешения `REQUEST_INSTALL_PACKAGES`, обхода StrictMode и версионирования `v1.5.19-beta` (versionCode 52).
* **Тестовая матрица на 4 виртуальных машинах (`test_dual_configuration_matrix.py`)**: Проверена работа DEX-байткода и графического рендеринга на профилях Darwin 1, 3, 5, 6 — 100% тестов пройдены успешно.
