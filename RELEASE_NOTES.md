# Release Notes — Яндекс Книги Lite v1.5.10

**Дата релиза:** 31 октября 2026 г.  
**Целевые платформы:** Onyx Boox Darwin 1 (Android 4.2.2 Jelly Bean, API 17, Rockchip RK3026), Darwin 3, 5, 6 (Android 4.4.4 KitKat, API 19, Freescale i.MX6), Onyx Boox Livingstone и все ридеры на базе Android с экранами E-Ink Carta.

---

## 🚀 Основные изменения в версии 1.5.10

### 1. Режим «Обратный ландшафт» (Reverse Landscape)
- Добавлена ориентация экрана «Обратный ландшафт» (`ActivityInfo.SCREEN_ORIENTATION_REVERSE_LANDSCAPE`, альбомная ориентация с поворотом на 180° относительно стандартного ландшафта).
- Обеспечено комфортное удержание ридера как левой, так и правой рукой (боковые аппаратные клавиши не перекрываются ладонью), а также чтение при подключенном кабеле зарядки.
- Реализовано циклическое переключение ориентации в меню настроек ридера: «Портрет» $\to$ «Ландшафт» $\to$ «Обр. ландшафт» $\to$ «Портрет».
- Адаптивное репагинирование и полноэкранное обновление E-Ink без артефактов при смене ориентации.

### 2. Двусторонняя облачная синхронизация прогресса чтения (Bookmate v5 API)
- Устранена критическая проблема, из-за которой позиция чтения, сделанная на ридере в режиме «онлайн», не отображалась на смартфоне в мобильном приложении Яндекс Книги.
- Взамен устаревших и отсутствующих на сервере путей (`/books/{uuid}/progress`, возвращавших HTTP 404) внедрен официальный протокол Bookmate API v5:
  * Первичная отправка через `PATCH /api/v5/profile/library_cards/bulk` с полным объектом позиции чтения (`last_reading_position`, `reading_position`, `position`, `chapter`, `paragraph`, `point`, `percent`, `reading_progress`, ISO-8601 `updated_at`, `last_read_at`).
  * Надежный каскадный fallback: `POST /api/v5/profile/library_cards` $\to$ `PATCH /api/v5/profile/library_cards/{id}` $\to$ `PUT /api/v5/profile/library_cards/bulk`.
- Внедрено debounced автосохранение прогресса во встроенном ридере: при листании страниц через 2.5 секунды после остановки на странице позиция автоматически отправляется в облако Яндекс Книг без спама сервера при быстром пролистывании.
- Корректная отмена таймеров автосохранения при выходе или переходе в фон (`onPause`, `onDestroy`, `onBackPressed`) с мгновенным сбросом очереди в сеть.

### 3. Исправление удаления книг с полок («Убрать с полки» синхронно со смартфоном)
- Устранена ошибка, при которой книги, убранные с полки на ридере (например, Darwin 5), оставались в мобильном приложении на смартфоне.
- Корневая причина заключалась в том, что эндпоинт `DELETE /api/v5/profile/library_cards/{id}` ожидает числовой ID карточки библиотеки (`card.id`), а не UUID книги. Запрос возвращал HTTP 404, который старый код ошибочно считал успешным.
- Реализован двухэтапный безопасный механизм:
  * Определение числового `card.id` из локальной SQLite базы или предварительного запроса `GET /api/v5/profile/library_cards?book_uuid={uuid}`.
  * Удаление через `DELETE /api/v5/profile/library_cards/{cardId}` с fallback на открепление книги от полок через `PATCH` со статусом `state: "none"`.
  * При удалении книги на ридере она гарантированно исчезает из полок в приложении на смартфоне.

### 4. Автоматическая привязка и хранение `card_id` в SQLite и моделях данных
- В таблицу `books` добавлена колонка `card_id TEXT` с автоматической миграцией `ALTER TABLE`.
- Модели данных `Book` и `ReadingProgress` расширены методами `getLibraryCardId()` и `setLibraryCardId()`.
- Автоматическая подгрузка `card_id` из локальной базы SQLite при запросах прогресса (`getProgress`) и извлечении накопившейся офлайн-очереди (`getPendingSyncQueue`).
- Метод смены полки `updateBookShelfState` расширен перегрузкой с прямым указанием `cardIdHint` для мгновенного обновления без избыточных запросов.
