# Release Notes — Яндекс Книги Lite v1.5.14-beta

> [!NOTE]
> **Статус выпуска:** Предварительная бета-версия (Beta / Preview).  
> Данная сборка включает результаты глубокого повторного аудита синхронизации между ридером и смартфоном, устраняет гонку стартового сохранения при открытии книги в `ReaderActivity`, исправляет переход на новую главу по проценту со смартфона, сохраняет полку «В планах» при простом скачивании книги в память и переводит все диалоги подтверждения на высококонтрастный E-Ink компонент `EinkNotice.showConfirm`.

**Дата релиза:** 1 ноября 2026 г.  
**Целевые платформы:** Onyx Boox Darwin 1 (Android 4.2.2 Jelly Bean, API 17, Rockchip RK3026), Darwin 3, 5, 6 (Android 4.4.4 KitKat, API 19, Freescale i.MX6), Onyx Boox Livingstone и все ридеры на базе Android с экранами E-Ink Carta.

## 🚀 Основные исправления и улучшения в версии 1.5.14-beta

### 1. Полная синхронизация позиции чтения со смартфона на ридер и обратно
- **Устранена гонка стартового сохранения (`ReaderActivity.renderCurrentPage`):** Ранее при первом открытии книги до завершения сетевого запроса `getReadingProgress` вызывался `saveProgress()`, который записывал `0.1%` с текущим временем `System.currentTimeMillis()`, блокируя применение более свежего прогресса со смартфона. Теперь сохранение прогресса выполняется только при реальном листании или переходе пользователем (`userHasInteracted`), а статус полки «Читаю» фиксируется отдельно.
- **Точный пересчет главы при чтении со смартфона (`DatabaseHelper` + `ReaderActivity.resolveInitialPositionAndOpen`):** Когда со смартфона приходит новый процент прочитанного (без внутреннего индекса главы ридера), устаревший локальный индекс главы сбрасывается, таблица `progress` гарантированно обновляется, и встроенный ридер открывает книгу точно на той главе и странице, которые соответствуют проценту со смартфона.

### 2. Корректная работа полок при скачивании и сбросе чтения
- **Скачивание про запас без смены полки (`MainActivity.ensureBookSavedForDownload`):** Нажатие кнопки «Скачать» в окне «О книге» (и пакетное скачивание полки) теперь скачивает файл книги в память устройства, оставляя книгу на её текущей полке («В планах»), тогда как открытие книги для чтения («Ридер Lite» / «NeoReader» / нажатие на карточку) переводит её в раздел «Читаю».
- **Исправлен сброс прогресса (`resetBookProgressAndMoveToPlans` и `DatabaseHelper.resetReadingProgress`):** Устранен конфликт, при котором после перевода книги в «В планах» повторный вызов `sendReadingProgress` возвращал книгу на сервере обратно в «Читаю». Очередь `sync_queue` при сбросе полностью очищается.

### 3. Высококонтрастные диалоги подтверждения `EinkNotice.showConfirm`
- Все окна подтверждения («Удалить файл», «Сбросить чтение», «Убрать с полки», «Выйти из аккаунта», «Нет подключения к интернету») переведены на единый E-Ink дизайн: чисто белый фон, четкая черная рамка 2.5dp, полное отсутствие серого затемнения фона (`FLAG_DIM_BEHIND` отключен).
