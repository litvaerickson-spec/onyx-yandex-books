# Release Notes — Яндекс Книги Lite v1.6.0 (Official Stable Release)

> [!IMPORTANT]
> **Официальный стабильный релиз (Stable Release)**  
> Версия **v1.6.0** (код сборки `54`) — первый стабильный релиз приложения «Яндекс Книги Lite» для электронных книг Onyx Boox и Android-устройств с экранами E-Ink Carta. Статус предварительного тестирования (Beta) завершен. Все модули — аппаратный E-Ink рендеринг, физические боковые кнопки, двусторонняя облачная синхронизация, эргономика сенсорных экранов, база данных SQLite и доставка обновлений по воздуху (OTA) — стабилизированы и прошли полное закрытое тестирование.

**Дата выпуска:** 1 ноября 2026 г.  
**Целевые платформы:** Onyx Boox Darwin 7, Darwin 6 (Carta Plus 300 DPI), Darwin 1 (Android 4.2.2 Jelly Bean, API 17, Rockchip RK3026), Darwin 3, 5 (Android 4.4.4 KitKat, API 19, Freescale i.MX6), Onyx Boox Livingstone, Poke, Nova, Note, Tab, Leaf, Page, Palma, а также все электронные книги на базе Android с экранами E-Ink Carta/Kaleido.

---

## 🏛️ Обобщение эволюции проекта: от версии 8 (v1.5.8) до стабильного релиза v1.6.0

За время разработки от версии 8 (v1.5.8 / v1.4.8) до официального стабильного выпуска **v1.6.0** архитектура приложения претерпела масштабную эволюцию по пяти фундаментальным направлениям:

### Раздел 1. Аппаратная интеграция с платформой Onyx Boox (E-Ink & Кнопки)
* **Аппаратный Onyx Android SDK (версии 2026 г.):**
  - Подключены официальные библиотеки `onyxsdk-device-1.3.6.aar`, `onyxsdk-base-1.8.9.aar` и `onyxsdk-pen-1.5.8.aar`.
  - Реализован фасад `EpdController.java` с динамической рефлексией и Graceful Degradation для обычных смартфонов и планшетов.
  - Активирован специализированный аппаратный режим **Regal (Clear screen)** для устранения артефактов и послесвечения электронных чернил без мерцания.
  - Реализована функция глубокой аппаратной очистки экрана `EpdController.applyGCOnce()` при смене глав и по долгому нажатию.
  - Внедрено двухканальное аппаратное управление подсветкой CTM (тёплый янтарь и холодный свет).
* **Физические боковые кнопки корпуса устройства:**
  - Полный перехват специализированных скан-кодов Onyx Boox: скан-коды `92` и `104` (листание назад), скан-коды `93` и `109` (листание вперед), клавиши `166/167` (CHANNEL) и `260/261` (NAVIGATE).
  - Ранний перехват через `dispatchKeyEvent()` в `ReaderActivity` и `MainActivity` до передачи в системное окно `PhoneWindow`: **системный ползунок регулировки громкости (`VolumePanel`) полностью заблокирован и никогда не появляется на экране E-Ink при чтении**.
  - Внедрена поддержка долгих нажатий через `event.startTracking()` для принудительного обновления экрана и подавление ложного автоповтора клавиш (`event.getRepeatCount() > 0`).

---

### Раздел 2. Сетевой стек и облачная синхронизация чтения (Apollo GraphQL & REST)
* **Протокол синхронизации с «Яндекс Книгами» (Bookmate v5):**
  - Реализована адресация контента по стандарту **EPUB 3 CFI (Canonical Fragment Identifier)**: прогресс привязывается к структуре книги (`/6/spine!/4/elem:0`), а не к абстрактным номерам страниц.
  - Внедрена поддержка шлюза **Apollo GraphQL v3 (`https://books.yandex.ru/node-api/p-graphql/`)** с обязательными заголовками `Apollo-Require-Preflight` и операциями `GetTextbookProgress` и `ProgressUpdated`.
  - Устранена фундаментальная ошибка смещения глав: отсечение технической обложки книги (`ch_0_cover`) исключило расхождение на 1 главу между мобильным приложением и электронным ридером.
  - Разработан алгоритм **взвешенного символьного смещения (Weighted Chapter Sync)**, предотвращающий ложные перескоки на короткие служебные разделы (вступления, благодарности).
  - Автоматический перевод книги из полки «В планах» в «Читаю» при первом открытии (онлайн или офлайн).
  - Защита от потери прогресса: двустороннее разрешение конфликтов по серверным временным меткам UTC (Last-Write-Wins) с выводом монохромных высококонтрастных диалогов подтверждения `EinkNotice.showConfirm()`.

---

### Раздел 3. Типографика, переносы TeX и сенсорная эргономика экранов высокого разрешения
* **Сенсорная эргономика на экранах Carta Plus 300 DPI (Onyx Boox Darwin 7):**
  - Устранена проблема промахов по кнопкам настроек: внедрена концепция **Full-Row Clickable Targets** — любая часть строки (название, переключатель, фон) является кликабельной зоной.
  - Увеличены минимальные размеры элементов интерфейса: высота строк до 42dp, высота кнопок до 36dp (с гарантированным `minHeight="36dp"`), кнопки пагинатора до 44–48dp.
  - Контейнерам верхней и нижней панели явно назначены атрибуты `android:clickable="true"` и `android:focusable="true"`, что полностью исключило пробой тач-событий на холст книги `readerCanvas` и случайное закрытие меню.
* **Типографический движок:**
  - Алгоритмические слоговые переносы слов по стандарту TeX (OpenOffice/LibreOffice ru-RU) без зависаний пагинатора.
  - Встроенный пакет из 8 высококонтрастных шрифтов E-Ink (включая Inglobal Apache 2.0).
  - Zero-Scroll архитектура диалога выбора шрифта: все гарнитуры отображаются на одном экране без скролла и артефактов.
  - Четыре пресета боковых полей (Сверх-узкие 8px, Узкие 18px, Средние 32px, Широкие 48px).
  - Поддержка трех ориентаций экрана: Портрет, Ландшафт и «Обратный ландшафт» (Reverse Landscape 270°).

### Раздел 4. Бесперебойная доставка обновлений по воздуху (OTA Update System)
* **Менеджер обновлений `AppUpdateManager`:**
  - Реализован **мульти-стратегический поиск версий**:
    1. Полнотекстовый парсинг последних релизов GitHub API (`/releases?per_page=10`) с корректным распознаванием всех форматов релизов.
    2. Прямой статический CDN-манифест `version.json` на `raw.githubusercontent.com` без ограничений GitHub API Rate Limit.
    3. Дополнительный fallback на `/releases/latest`.
* **Автоматическое обнаружение обновлений при включении Wi-Fi:**
  - Внедрен динамический широковещательный приемник `ConnectivityReceiver` в `MainActivity`. Когда электронная книга подключается к Wi-Fi после выхода из спящего режима, приложение автоматически проверяет наличие свежих релизов и синхронизирует очередь чтения.
* **Совместимость с современными версиями Android:**
  - Добавлено системное разрешение `android.permission.REQUEST_INSTALL_PACKAGES` для Android 8/9/10/11.
  - Реализован безопасный обход `FileUriExposedException` в `installApk()` через временное отключение жестких проверок StrictMode и флаг `FLAG_GRANT_READ_URI_PERMISSION`.

---

### Раздел 5. Отказоустойчивость, база данных SQLite v8 и Crash-Proof архитектура
* **Инкремент базы данных до `DATABASE_VERSION = 8`:**
  - Схемы таблиц `progress`, `sync_queue`, `books` и `bookmarks` обновлены до полного канонического DDL со столбцами `document_uuid` и `cfi`.
* **Самовосстановление схемы базы данных (Self-Healing Schema Auto-Migration):**
  - Метод `ensureSchemaMigration()` вызывается не только в `onCreate()` и `onUpgrade()`, но и при каждом обращении к базе в `onOpen()`. При обнаружении старой структуры база данных на лету достраивает недостающие колонки без потери сохраненных книг и закладок.
* **Тотальная изоляция UI потока ридера (100% try-catch isolation):**
  - Все методы перелистывания страниц (тапом и физическими кнопками) и сохранения прогресса в `ReaderActivity` и `SyncManager` защищены блоками перехвата исключений. Полностью исключена ошибка «В приложении Яндекс книги произошла ошибка».
