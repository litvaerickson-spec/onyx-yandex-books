## 🚀 Ключевые нововведения и исправления по отзывам пользователей 4PDA

### 1. Архив версий и механизм отката ПО (Downgrade + Zero Data Loss)
* В главное меню приложения и в окно проверки обновлений добавлен раздел **«Архив версий и откат ПО»**.
* Приложение загружает список всех выпущенных релизов напрямую с GitHub (`v1.7.0-beta`, `v1.6.0`, `v1.5.20-beta` и др.) и позволяет выбрать любую предыдущую версию.
* Перед откатом на более старую сборку и при выходе из приложения автоматически создается полная резервная копия базы данных (`yandex_books_lite.db`), токена авторизации и настроек в папке `/sdcard/Books/YandexBooks/backup/`. При установке старой версии с нуля данные подхватываются автоматически.

### 2. Полная совместимость с Android 12, 13 и 14 (Onyx Boox Go 10.3, Bigme B6)
* Параметр `targetSdkVersion` повышен с `19` до **`28`** (при сохранении `minSdkVersion="17"` для старых ридеров Darwin 1–6).
* Полностью устранена блокировка установки APK на Android 14 (`INSTALL_FAILED_DEPRECATED_SDK_VERSION`) и предупреждения о несовместимости без использования ADB.
* Пакет подписан тройной криптографической подписью **APK Signature Scheme v1 + v2 + v3**.

### 3. Адаптация интерфейса для 10.3" экранов и редизайн меню
* **Устранена обрезка текста на кнопках (`Чита...`, `О кни...`):** в карточке книги фиксированная ширина `64dp` заменена на адаптивную `wrap_content` с комфортными внутренними отступами.
* **Новые масштабы `180%` и `200%`:** специально для крупных экранов 10.3" с разрешением 2480×1860 (300 PPI) расширен диапазон масштабирования интерфейса и добавлено пропорциональное масштабирование высот панелей (`UiScaleHelper.applyViewTreeScale`).
* **Понятное управление главным меню:** вместо одной кнопки «Закрыть» в нижней части меню теперь расположены две отдельные кнопки — **`[ Свернуть меню ]`** (возврат к полке) и **`[ Выйти из приложения ]`** (полное закрытие программы).

### 4. Прямое переключение на AlReader и NeoReader в один клик
* Кнопка режима чтения в верхней панели теперь переключает режимы по кругу: **`Lite`** $\to$ **`NeoReader`** $\to$ **`AlReader`** $\to$ **`Выбор`**, а при долгом нажатии открывает удобное окно выбора.
* В диалоге «О книге» добавлена прямая кнопка **`[ AlReader ]`** рядом с `[ NeoReader ]` и `[ Ридер Lite ]`. Больше не нужно перенастраивать ассоциации файлов по умолчанию в системной библиотеке Onyx.

### 5. Исправление оглавления и прогресса в многотомниках («Всадники Перна» 4-в-1)
* В `EpubParser` исправлена коллизия одноименных файлов глав из разных подпапок архива (`Book1/ch05.xhtml` vs `Book4/ch05.xhtml`).
* Для вложенных глав многотомников формируются полные заголовки с указанием тома (например, `Книга 4 • Глава 17`).
* В `ReaderActivity` устранен преждевременный обрыв поиска в `findActiveTocTitle()` и синхронизированы верхний и нижний заголовки главы.

### 6. Режим тап-зон «Для левшей» и расширенный нижний колонтитул
* В настройках «Формат $\to$ Вид» добавлен переключатель **«Зоны касания экрана»**:
  - `Стандарт` (левый край — Назад, правый край — Вперед, центр — Меню).
  - `Для левшей` (левый край делится по вертикали: верхние 30% и нижние 30% листают **Вперед**, а центральные 40% слева листают **Назад**).
  - `Верх/Низ` (верхние 30% — Назад, нижние 40% — Вперед).
* В нижнем колонтитуле страницы теперь отображаются:
  - **Слева:** текущее системное время и заряд батареи (`16:22 • 97%`).
  - **Справа:** страница внутри текущей главы, сквозная страница всей книги и общий процент (`Гл. 4/18 • Стр. 2373 из 2612 (91%)`).
