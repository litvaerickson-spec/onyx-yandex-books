# Яндекс Книги Lite v2.0.2-beta — Исправления каталога, читаемости всплывающих окон, быстрого масштабирования и открытия книг

## Статус тестового выпуска (BETA)

• **Перед установкой:** перед вами тестовая BETA-версия **2.0.2-beta**, подготовленная по результатам проверки версии **2.0.1-beta** на реальных устройствах. Если вы не сталкиваетесь с перечисленными ниже моментами, мы не рекомендуем пока обновляться до тестовой сборки — при необходимости всегда можно остаться на текущей версии или откатиться через раздел «Архив версий».
• **Область проверки:** все исправления проверены программными тестами ядра и на матрице эмуляторов Android (версии 4.2.2, 4.4.4, 5.1.1, 6.0.1 и 9.0). На различных моделях физических устройств требуется контрольная проверка после обновления.
• **Совместимость с предыдущими версиями:** приложение сохраняет авторизацию и пользовательские настройки автоматически. При откате на версию **1.6.0** Android очищает книги во внутреннем кэше — потребуется повторный вход в Яндекс ID и повторная загрузка книг.

## Что должно быть устранено в версии 2.0.2-beta

1. **Ошибка при выборе каталога и полок («Нет подключения к интернету» / 404)**:
• Устранены устаревшие идентификаторы полок, возвращавшие ошибку 404 на сервере.
• По умолчанию подключена динамическая витрина актуальных поисковых подборок (`/api/v5/popular_searches/ru`) с автоматическим переходом на подтверждённые рабочие полки Яндекс Книг («Только в Яндекс Книгах», «Главные новинки», «Подборка редакции» и другие).
• Исправлена обработка ошибок сети в каталоге: сообщение «Нет подключения к интернету» больше не выводится ложно при включённом Wi-Fi — вместо этого отображается корректное уведомление об ошибке категории с кнопкой «Повторить».

2. **Нечитаемый мелкий текст и большие поля во всплывающих окнах сносок и выделения цитат**:
• Текст во всплывающих окнах переведён из бледного серого цвета (`Color.DKGRAY`) в глубокий контрастный чёрный (`#000000`), оптимальный для экранов E-Ink Carta.
• Кегль шрифта сносок и цитат увеличен с 13.5 sp до 15.5–20 sp и динамически масштабируется вместе с выбранным размером шрифта книги.
• Внутренние пустые поля диалоговых окон уменьшены с 16 dp до 10–11 dp, а ширина окна увеличена до 94% экрана, что обеспечивает комфортное чтение длинных примечаний.
• Кнопки действий («Копировать», «Создать цитату», «Закрыть») увеличены до 14.5 sp (жирное начертание, высота 40 dp), устранено дублирование кавычек (`««...»`), а при открытии и закрытии окна инициируется аппаратное обновление экрана E-Ink для устранения остаточных следов (ghosting).

3. **Задержка при изменении размера шрифта (реализация мгновенного отклика по принципу Apple Books)**:
• Переработан алгоритм изменения кегля: видимая страница пользователя перерисовывается мгновенно (~5–15 мс) непосредственно из оперативной памяти с сохранением точного якоря позиции чтения через метод `paginateSinglePageFromOffset`.
• Полный пересчёт текущей главы запускается в фоновом режиме с задержкой 260 мс (debounce) без блокировки интерфейса и без рывков экрана.
• Полная фоновая пагинация всей книги и пересчёт общего числа страниц перенесены в фоновый поток с минимальным приоритетом (`Thread.MIN_PRIORITY`) с последующим мягким обновлением нижнего колонтитула.
• Внедрено кэширование начертаний `Typeface` и измерений ширины слов в `StyleMeasurer`, снизившее количество ресурсоёмких вызовов измерения шрифта в 2.5–3 раза.

4. **Длительное открытие книг в Lite-режиме**:
• Устранён квадратичный повторный разбор HTML при вычислении смещений якорей оглавления книги (алгоритм `estimateAnchorCharOffsetFast` и оптимизированный строковый поиск идентификаторов якорей).
• Загрузка глав с накопителя ускорена за счёт прямого чтения через байтовый буфер вместо построчного `BufferedReader`.
• Фоновый пре-подсчёт страниц всей книги отложен на 1200 мс после успешного отображения первой страницы, отдавая весь процессор мгновенной отрисовке текста для чтения.
• Для крупных глав размером более 12 КБ добавлена быстрая предварительная отрисовка первого экрана.
