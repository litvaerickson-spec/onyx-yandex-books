## Что нового в v1.3.0

В версии **1.3.0** реализовано встроенное бесшовное обновление приложения (OTA Self-Update) прямо с книги через GitHub Releases, а также полностью переработано диалоговое окно «О книге» для максимальной эргономики на E-Ink экранах Onyx Boox.

---

### 🚀 1. Встроенное обновление с GitHub Releases (OTA Self-Update)
- **Обновление в один клик прямо с ридера**: больше не нужно подключать книгу к компьютеру, удалять старое приложение или вручную копировать APK.
- **Полное сохранение сессии и прогресса**: при установке поверх существующей версии Android сохраняет базу данных SQLite, авторизацию, токены и кэш скачанных книг (`/sdcard/Books/YandexBooks/`) — повторный вход не требуется!
- **Автоматическая проверка обновлений**:
  - При запуске приложение в фоновом режиме опрашивает GitHub API (`litvaerickson-spec/onyx-yandex-books`).
  - При наличии новой версии в шапке появляется акцентная кнопка `[ ⬆ vX.Y.Z ]`.
  - В нижней панели щелчок по `v1.3.0` или кнопка `[ ⬆ Обн. ]` в шапке открывает диалог проверки обновлений.
- **Информативный диалог релиза**: отображается номер версии, размер пакета и полный список изменений (Changelog) с возможностью скачать и запустить установку прямо в системе.

---

### 🎨 2. Полная оптимизация диалогового окна «О книге»
- **Эффективное использование площади E-Ink**: окно диалога теперь занимает 92% ширины и 85% высоты экрана.
- **Приоритет аннотации (60%+ высоты)**: текстовое описание книги расширено до 14–16 видимых строк с приятным межстрочным интервалом и плавной прокруткой вместо прежних 3 строчек.
- **Компактная шапка**:
  - Название книги: 14sp bold, компактные отступы, максимум 2 строки.
  - Метаданные: автор, процент прочитанного и статус хранения в памяти объединены в две аккуратные строки.
- **Эргономичный 2-строчный блок действий (вместо 4 громоздких вертикальных кнопок)**:
  - **Строка 1**: Кнопки чтения бок о бок (50% / 50%): `[ 📖 Onyx Reader ]` (акцентная) и `[ ⚡ Читалка Lite ]` (контурная).
  - **Строка 2**: `[ 📥 Скачать EPUB ]` и `[ ✕ Закрыть ]` (для сетевой книги) либо `✔ В памяти (/sdcard/Books/...)` и `[ ✕ Закрыть ]` (для сохраненной).
  - Высота блока кнопок сократилась более чем в 2 раза, освободив всё пространство для чтения аннотации.

### 📦 Установка и обновление
- Если у вас уже установлена версия 1.2.9: просто установите `yandex-books-lite-v1.3.0.apk` поверх существующей версии. Начиная с v1.3.0, все будущие версии можно будет обновлять в 1 клик прямо из приложения!
