# Яндекс Книги Lite v1.3.6

## 🚀 Что нового в версии 1.3.6:

### 1. Исправление ошибки при нажатии на «Содержание»
- **Причина сбоя**: При обновлении с предыдущих версий без предварительного удаления приложения версия SQLite базы оставалась старой, из-за чего таблица `bookmarks` не создавалась и запрос списка закладок вызывал аварийное закрытие.
- **Решение**: Версия базы данных повышена до 4 (`DATABASE_VERSION = 4`), добавлена проверка и автоматическое создание таблицы `bookmarks` при любом обращении, а также полное оборачивание модального окна оглавления в безопасный блок `try-catch`.

### 2. Устранение ложного 100% прогресса и закидывания в конец книги
- **Причина сбоя**: Поле `progress: 1` карточки Bookmate API ошибочно трактовалось как дробь $1.0 = 100\%$, из-за чего книга принудительно помечалась прочитанной, при открытии позиция отматывалась на последнюю страницу последней главы (выходные типографские данные), а кнопка следующей главы сообщала «Это последняя глава книги».
- **Решение**: 
  - Исправлен парсер `extractProgress`: статусное поле `progress` больше не превращается в 100%. 
  - Число `1.0` теперь означает $1\%$ (начало книги), если статус не равен явно «прочитано».
  - Поиск позиции ориентируется строго на объекты `last_reading_position`, `reading_position` и `position`.
  - При открытии книги с завершенным статусом ридер стартует с Главы 1 для комфортного перечитывания.

### 3. Исправление облачной синхронизации со смартфоном
- Серверный прогресс со смартфона теперь имеет абсолютный приоритет при наличии более свежей временной метки (`timestamp`).
- Встроена автоматическая очистка искаженных 100% записей при обновлении базы данных.
- Индекс главы из облака применяется напрямую без погрешностей математического пересчета.

### 4. Визуальное разделение автора и названия книги
- В диалоге «О книге» ФИО автора переведено на обычный тонкий шрифт (`Typeface.NORMAL`), что исключает слияние с жирным заголовком.
