## 🌟 Главные новшества версии 1.3.5

1. **🔄 Безупречная синхронизация позиции чтения без ложных перескоков и затирания**:
   - Внедрен взвешенный расчет прогресса по длине глав в байтах и символах вместо наивного деления на число глав EPUB.
   - Устранена ошибка открытия книги в конце (например на главе «Слова благодарности» при 51% прогресса) и преждевременной перезаписи облачной позиции на 40%.
   - Введена защита `isInitialLoading`: первичное открытие книги больше не затирает прогресс чтения в БД и облаке.
   - Место чтения точно мапится на конкретную страницу через внутриглавное символьное смещение `anchorCharOffset`.
2. **🖋️ Элегантная типографика авторов**:
   - ФИО автора отображается тонким/нормальным начертанием (`textStyle="normal"`), визуально и гармонично разделяясь от жирного заголовка книги.
3. **⚙️ Трехсекционная панель форматирования в стиле Onyx NeoReader**:
   - Меню настроек разделено на 3 просторные подвкладки без обрезки текста:
     - `[ Вид ]`: ползунок размера шрифта (`—` [SeekBar] `+`, от 12 до 36 sp), выбор гарнитуры (`Serif ∨`, `Sans-Serif ∨`, `Monospace ∨`), настройка абзацного отступа (`0 px ∨`, `20 px ∨`, `32 px ∨`, `44 px ∨`).
     - `[ Формат ]`: переключатель жирности текста (`Жирный` / `Обычный`), слоговые переносы TeX (`Включены` / `Отключены`), режим контрастности E-Ink (`Высокий` / `Обычный`).
     - `[ Между строк ]`: межстрочный интервал (`1.00x ∨`, `1.25x ∨`, `1.50x ∨`, `1.75x ∨`), боковые поля (`Узкие (18) ∨`, `Средние (32) ∨`, `Широкие (48) ∨`), вертикальные поля (`Малые ∨`, `Стандарт ∨`, `Большие ∨`).
4. **📑 Полноценное интерактивное оглавление и менеджер закладок**:
   - Меню «Содержание» содержит 2 сегментированные вкладки: `[ Оглавление ]` и `[ Закладки ]`.
   - В `[ Оглавление ]`: перечень глав с подсветкой читаемой главы (`▶ Глава X (читается)`).
   - В `[ Закладки ]`: кнопка `[ + Добавить текущую страницу в закладки ]`, список сохраненных мест с номером главы, страницы, цитатой (сниппетом текста), датой/временем, быстрым переходом и удалением `✕`. Сохранение в локальной базе данных SQLite.

## 📲 Порядок установки и обновления

1. Загрузите файл **[`yandex-books-lite-v1.3.5.apk`](https://github.com/litvaerickson-spec/onyx-yandex-books/releases/download/v1.3.5/yandex-books-lite-v1.3.5.apk)**.
2. Скопируйте APK в память ридера (через USB или MicroSD-карту).
3. На ридере откройте **«Диспетчер файлов»** и нажмите на файл для установки.
4. Приложение обновится поверх существующей версии — авторизация и скачанные книги сохранятся.
   *(Или воспользуйтесь кнопкой обновления прямо внутри приложения!)*
