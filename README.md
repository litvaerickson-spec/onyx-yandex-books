## ✨ Ключевые возможности

1. **Автономность**: APK устанавливается прямо на электронную книгу и работает самостоятельно.
2. **Безопасность и современный TLS**: Встроенный Google Conscrypt обеспечивает работу с TLS 1.2 и TLS 1.3 на старых версиях Android.
3. **Эргономичная авторизация**: Вход в Яндекс по QR-коду или короткому коду через `ya.ru/device` (без ввода паролей на медленной клавиатуре читалки).
4. **Все режимы чтения**:
   - Потоковое онлайн-чтение по главам.
   - Автоматическое кэширование книги в память при открытии (с возможностью отключить Wi-Fi).
   - Ручная кнопка «Скачать офлайн» для выбранных книг.
5. **Умная синхронизация (Smart Conflict Resolution)**: Если вы читали ту же книгу на телефоне, читалка не перезапишет прогресс, а предложит перейти к актуальной позиции.
6. **E-Ink оптимизация**:
   - Нативный Canvas-рендерер (потребление RAM ~15–20 МБ вместо тяжелого WebView).
   - Мгновенная смена страниц без анимаций.
   - Поддержка физических кнопок перелистывания Darwin (`PAGE_UP`/`PAGE_DOWN`).
   - Настраиваемый цикл очистки остаточных артефактов (Ghosting).
7. **Типографика уровня AlReader**:
   - Словари переносов слов TeX Hyphenation (русский и английский языки).
   - Выравнивание по ширине (Justify) без «дыр» между словами.
   - Поддержка пользовательских шрифтов `.ttf`/`.otf` из папки `Fonts`.
   - Инлайн-сноски прямо на текущей странице.
