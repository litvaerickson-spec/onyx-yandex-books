## 🌟 Главные новшества версии 1.3.2

1. **📚 Каталог рекомендаций и популярных книг**:
   - Полноценная вкладка `[ Каталог ]` с актуальными подборками бестселлеров и рекомендациями от Яндекс Книг.
   - Загрузка книг напрямую из каталога без необходимости предварительного добавления через телефон.
2. **🔍 Глобальный поиск книг через Bookmate GraphQL**:
   - Вкладка `[ Поиск ]` с компактной строкой ввода и экранной клавиатурой.
   - Мгновенный поиск по всей библиотеке Яндекс Книг по авторам и названиям.
3. **📌 Добавление книг в личную полку («В планы»)**:
   - В карточке любой книги из каталога или поиска доступна кнопка `[ В планы ]`.
   - Книга мгновенно привязывается к вашему аккаунту Яндекс ID через API карточек библиотеки и отображается на всех ваших устройствах.
4. **🎯 Чистый E-Ink интерфейс и реорганизация навигации**:
   - **4 равные вкладки** библиотеки: `[ Читаю ]`, `[ В планах ]`, `[ Каталог ]`, `[ Поиск ]`.
   - Полка «Прочитано», синхронизация, сброс экрана E-Ink и выход вынесены в модальное `[ Меню ]`.
   - Встроенная читалка переименована в **«Онлайн»** (вместо непонятного термина «Lite»). Переключатель в шапке: `[ Onyx ]` / `[ Онлайн ]`.
   - **Тотальное удаление смайликов и эмодзи** со всех кнопок, плашек и диалогов — строгий профессиональный вид для экранов на электронных чернилах.
5. **🔄 Оптимизация диалога встроенного OTA-обновления**:
   - Описание релиза автоматически очищается от сырой Markdown-разметки (решетки, звездочки, теги) и выводится аккуратным списком.
   - Кнопки `[ Обновить ]` и `[ Позже ]` компактны и гарантированно не обрезаются на экранах любого разрешения (1024×758, 1448×1072).

## 📲 Порядок установки и обновления

1. Загрузите файл **[`yandex-books-lite-v1.3.2.apk`](https://github.com/litvaerickson-spec/onyx-yandex-books/releases/download/v1.3.2/yandex-books-lite-v1.3.2.apk)**.
2. Скопируйте APK в память ридера (через USB или MicroSD-карту).
3. На ридере откройте **«Диспетчер файлов»** и нажмите на файл для установки.
4. Приложение обновится поверх существующей версии — авторизация и скачанные книги сохранятся.
   *(Или воспользуйтесь кнопкой обновления прямо внутри приложения!)*
