## 🌟 Главные новшества версии 1.3.4

1. **🚀 Ликвидация зависания онлайн-читалки**:
   - Полностью устранена проблема мертвого зависания диалога «Загрузка и подготовка книги к чтению...».
   - Ресурсоемкий парсер `Html.fromHtml` и тяжелые регулярные выражения заменены на быстрый потоковый $O(N)$ парсер без аллокаций.
   - Защита фонового потока блоками `catch (Throwable)` предотвращает крах при Dalvik OutOfMemoryError на объемных произведениях.
   - Диалог сделан отменяемым кнопкой `[ Отмена ]` с 25-секундным таймером автозакрытия.
2. **📖 Двукратное сокращение межстрочного интервала в заголовках**:
   - Названия книг в списках полок, каталога и поиска отображаются компактно и аккуратно без излишних пустых отступов, оставаясь 100% читаемыми целиком.
3. **🎨 Интерфейс онлайн-читалки в стиле Onyx NeoReader**:
   - Верхняя панель: кнопка «Назад» (`<`), заголовок книги, кнопка аппаратного сброса E-Ink экрана `[ Сброс ]`, закрытие оверлея (`✕`).
   - Нижняя панель: заголовок текущей главы с кнопками перехода (`<<`, `>>`), интерактивный слайдер страниц `SeekBar` с кнопками шага и счетчиком `X/Y (Z%)`.
   - 3 функциональные вкладки:
     - `[ Содержание ]`: список всех глав с подсветкой текущей и быстрым переходом.
     - `[ Прогресс ]`: процент прочтения, номера глав/страниц и кнопка мгновенной облачной синхронизации.
     - `[ Формат ]`: панель настройки кегля шрифта (`A-`/`A+`), полей, межстрочного интервала, переносов и контрастности.
   - Аппаратная кнопка «Назад» сначала закрывает открытые меню читалки перед выходом в библиотеку.

## 📲 Порядок установки и обновления

1. Загрузите файл **[`yandex-books-lite-v1.3.3.apk`](https://github.com/litvaerickson-spec/onyx-yandex-books/releases/download/v1.3.3/yandex-books-lite-v1.3.3.apk)**.
2. Скопируйте APK в память ридера (через USB или MicroSD-карту).
3. На ридере откройте **«Диспетчер файлов»** и нажмите на файл для установки.
4. Приложение обновится поверх существующей версии — авторизация и скачанные книги сохранятся.
   *(Или воспользуйтесь кнопкой обновления прямо внутри приложения!)*
