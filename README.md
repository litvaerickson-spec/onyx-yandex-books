## 🌟 Главные новшества версии 1.2.8

1. **🏛️ Фиксированная нижняя панель (Footer Bar) и устранение пустоты внизу экрана**:
   - Внизу главного экрана закреплен аккуратный E-Ink статус-бар (30dp), исключающий неиспользуемую пустоту при малом числе книг.
   - Вывод информации о текущей полке: `📚 Читаю: 2 книги`.
   - Встроенные кнопки постраничной навигации: `[ ◀ Стр ]  1/1  [ Стр ▶ ]` для мгновенного постраничного перелистывания длинных списков (например, полки «В планах»).
2. **🎮 Поддержка аппаратных клавиш перелистывания Darwin на главном экране**:
   - Физические боковые кнопки ридера (`PAGE_UP`/`PAGE_DOWN` и `VOLUME_UP`/`VOLUME_DOWN`) теперь листают библиотеку книг постранично без необходимости сенсорных свайпов.
3. **🎨 Четкие кнопки в окне авторизации без обрезки текста**:
   - Кнопки «← Назад», «Клавиатура», «Ввод текста» и «↻» переведены на векторный стиль `@drawable/btn_eink` с явными отступами и высотой 28dp. Текст кнопок теперь 100% четкий, жирный и не срезается.
   - Строка подсказки отображается компактно в одну строку без многоточия на середине фразы.
4. **📱 Адаптивный QR-код в Яндекс ID без вертикального скролла**:
   - Периодическая CSS-инъекция и зум 70% скрывают лишний веб-футер Яндекса, уменьшают заголовки до 13px и центрируют QR-код строго в пределах экрана 758×1024.
5. **📖 Пропорциональная карточка книги и статус без усечения**:
   - Обложка увеличена до гармоничных 62×90dp (соотношение 2:3).
   - Аннотация книги расширена до 3 строк с комфортным интервалом 1.15.
   - Статус чтения и памяти форматируется как `0% • ☁ В сети` (или `24% • ✔ В памяти`) — бейдж больше никогда не обрезается до `• ☁ В с...`.
6. **⚡ Ультракомпактная верхняя панель (58dp)**:
   - Шапка приложения (28dp) и вкладки полок (28dp) подтянуты вплотную к верхнему статус-бару книги Darwin.

## 📲 Порядок установки и обновления

1. Загрузите файл **[`yandex-books-lite-v1.2.8.apk`](https://github.com/litvaerickson-spec/onyx-yandex-books/releases/download/v1.2.8/yandex-books-lite-v1.2.8.apk)**.
2. Скопируйте APK в память ридера (через USB или MicroSD-карту).
3. На ридере откройте **«Диспетчер файлов»** и нажмите на файл для установки.
4. Приложение обновится поверх существующей версии — авторизация и скачанные книги сохранятся.
