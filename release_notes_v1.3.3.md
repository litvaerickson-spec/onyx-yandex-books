# 📚 Яндекс Книги Lite для Onyx Boox — Релиз v1.3.3

### 🎯 Главные исправления и улучшения:

1. **Исправление ошибки чтения книг из Каталога и Поиска**:
   - Устранена ошибка сервера (HTTP 403 / 422) при попытке чтения и скачивания новых книг прямо из Каталога рекомендаций или глобального Поиска.
   - Реализована автоматическая привязка книги к профилю пользователя (`POST /profile/library_cards`) перед запросом файла книги и сохранение записи в локальную базу данных SQLite.
   - Исправлена отправка заголовков: бинарный заголовок `Accept: */*` теперь корректно переопределяет JSON-заголовок, обеспечивая стабильную отдачу EPUB-файлов серверами Bookmate.
   - Добавлен автоматический многоуровневый fallback: при неудачной попытке прямого скачивания приложение автоматически связывает книгу с аккаунтом и повторяет загрузку через резервные точки контента (`/content/v4`, `/content`, `/file`).

2. **100% полное отображение названий и авторов книг**:
   - Во всех списках (Полки, Каталог, Поиск) сняты ограничения на количество строк (`maxLines`) и многоточия (`ellipsize`).
   - Названия книг любой длины и полные ФИО авторов теперь переносятся на новые строки и видны целиком от первого до последнего символа.
   - В модальном окне «О книге» заголовок также отображается полностью без обрезки.

3. **Чистые списки книг без визуального мусора**:
   - Краткие аннотации полностью убраны из элементов списков, освобождая экранное пространство под полные названия и имена авторов.
   - Подробная аннотация книги доступна по кнопке «О книге» в просторном модальном окне.

4. **Сохранение контекста при чтении из Поиска и Каталога**:
   - При возврате из читалки обратно в каталог или результаты поиска список не сбрасывается и не очищается.
   - В выдаче поиска исключены аудиокниги (`AudioBook`), не содержащие текстового EPUB-формата.
