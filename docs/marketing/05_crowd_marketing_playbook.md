# Плейбук крауд-маркетинга и партизанского посева: «Яндекс Книги Lite для Onyx Boox»

## 🎯 Стратегическая цель
Органично перенаправлять пользователей, страдающих от плохой работы или несовместимости официального приложения «Яндекс Книги», в наш Open Source проект на GitHub и топик на 4PDA, не вызывая подозрений в коммерческой рекламе или спаме.

### Сценарий 4. Reddit (r/Onyx_Boox / r/ereader)
* **Триггер/Ситуация:** Пост пользователя:  
  *«Is there any way to read Yandex Books / Bookmate subscription on older Onyx Boox readers running Android 4.4? The official APK crashes immediately on startup.»*
* **Тон:** Инженерная помощь международному сообществу.
* **Текст ответа:**
  > "The official Yandex Books app crashes because it requires Android 7+ and relies on a Chromium WebView layer that easily consumes 300+ MB of RAM (which instantly crashes the 512 MB memory limit of Rockchip-based Onyx readers). Additionally, Android 4.x stock crypto lacks modern TLS 1.2/1.3 cipher suites.
  > 
  > Check out this open-source native client created specifically for Onyx Boox e-ink devices:
  > https://github.com/litvaerickson-spec/onyx-yandex-books
  > 
  > Key advantages:
  > • 100% native Canvas rendering (15–20 MB RAM footprint, instantaneous page turns).
  > • Conscrypt BoringSSL JNI backporting TLS 1.3 to Android 4.2+.
  > • 1-click authentication via QR-code / Device Code (ya.ru/device) — no tedious password typing on E-Ink.
  > • Hardware paging buttons & EPD ghosting refresh support.
  > • Bidirectional progress & shelf synchronization with your phone.
  > 
  > Pre-built signed APKs are available in GitHub Releases."

## 🛡️ Правила безопасности крауд-маркетинга (Антибан)

1. **Правило прогрева аккаунтов на 4PDA:**
   * Категорически запрещено создавать новые аккаунты специально для публикации ссылок.
   * На 4PDA ссылки от аккаунтов со стажем менее 14 дней и менее 15 сообщений автоматически блокируются спам-фильтрами.
   * В профиле аккаунта желательно указать модель ридера (например: *Onyx Boox Darwin 3*).
2. **Принцип «Сначала ценность — потом ссылка»:**
   * Никогда не бросайте голые ссылки. Сначала подробно объясните техническую причину проблемы (Android 4.x, TLS 1.3, Chromium WebView, 512 МБ ОЗУ). Это демонстрирует экспертизу, вызывает доверие модераторов и пользователей.
3. **Упоминание альтернатив (Нейтралитет):**
   * В сообщениях на форумах всегда упоминайте и другие пути решения: *«Если книги свои — ставьте AlReaderX; если по подписке Плюса — вот клиент на гитхабе»*. Это полностью исключает обвинения в ангажированности.
4. **Только доверенные домены:**
   * Никаких сокращателей ссылок (`bit.ly`, `clck.ru` и т.д.) или файлообменников с рекламой. Разрешены только:
     - `4pda.to` (внутренние ссылки форума);
     - `github.com` (наивысший авторитет для IT-модераторов).
5. **Интервалы публикации:**
   * Не более 1–2 нативных ответов в день по разным веткам. Массовый наплыв однотипных упоминаний за один час воспринимается модераторами форума как спам-атака.
