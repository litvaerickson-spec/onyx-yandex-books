## Яндекс Книги Lite v1.3.2 для Onyx Boox

### Что нового в версии 1.3.2:

1. Каталог рекомендаций и бестселлеров:
   • Добавлена вкладка «Каталог» с актуальными подборками популярных книг от Яндекс Книг.
   • Прямое скачивание и чтение книг из каталога на читалке.

2. Глобальный поиск книг через Bookmate GraphQL:
   • Полноценный поиск по авторам и названиям среди миллионов книг сервиса.
   • Быстрый вызов экранной клавиатуры и комфортный ввод поискового запроса.

3. Добавление книг в личную библиотеку («В планы»):
   • Кнопка «В планы» в карточке любой найденной книги или книги из каталога.
   • Мгновенная облачная синхронизация с мобильным приложением через API библиотеки Яндекс ID.

4. Реорганизация E-Ink навигации и строгое оформление:
   • 4 равные вкладки: «Читаю», «В планах», «Каталог», «Поиск».
   • Полка «Прочитано», синхронизация и настройки аккуратно вынесены в модальное «Меню».
   • Читалка переименована в «Онлайн» вместо «Lite». Переключатель: [ Onyx ] / [ Онлайн ].
   • Полное удаление смайликов и эмодзи из всех кнопок, плашек и диалогов для идеальной четкости E-Ink шрифтов.

5. Оптимизация диалога встроенного обновления:
   • Чистый и компактный вывод текста обновления без обрезки и спецсимволов.
   • Кнопки [ Обновить ] и [ Позже ] гарантированно помещаются на экранах любого разрешения.
